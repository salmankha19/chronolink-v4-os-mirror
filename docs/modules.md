# ChronoLink V4 Modules

This document lists the initial module stubs and their responsibilities.

- src/platformDependentLayer: board-level definitions and defaults.
- src/platformIndependentLayer: platform-independent ABI for GPIO/I2C/SPI/sensors/config.
- src/hardwareAccessLayer: MCU-specific driver implementations.
- src/svc: service and engine logic.
- src/app: application-level UI and flows.
