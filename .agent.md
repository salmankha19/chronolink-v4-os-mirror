# Chronolink v4 OS — Agent Rules

## Project
- ESP-IDF project using PlatformIO. Build with `pio run`. Upload with `pio run -t upload`.
- Target chip: ESP32-S3. Be mindful of PSRAM allocation and heap fragmentation.
- Terminal: PowerShell (Windows).

## Code Style
- Match existing codebase conventions (4-space indent).
- Use `snake_case` for functions, `UPPER_SNAKE_CASE` for macros.
- Check return values of all ESP-IDF APIs (`ESP_ERROR_CHECK` or explicit handling).

## Architecture
- Follow the existing HAL abstraction pattern in `components/hal/`.
- Do not call ESP-IDF drivers directly from application code; go through HAL.
- FreeRTOS tasks must have explicit stack sizes and priorities documented.

## Do Not Touch
- `managed_components/` — auto-generated by the component manager.
- `build/` — build artifacts.
- `sdkconfig` — regenerate via `menuconfig` if needed, don't hand-edit.

## Git
- Never commit directly to `main`. Use feature branches.
- Commit messages: conventional commits (`feat:`, `fix:`, `chore:`, `docs:`).
