Setup Authentication

The device prints a one-time API token to its serial console on first boot. Paste it here. It is stored in this browser only and sent with every configuration request. Without it, POST endpoints reply 403.

Location & Calculation

Fills latitude, longitude, calculation method, madhab and Hijri options, and applies the city preset on the device — which also sets the timezone. Adhan margins and jamat times are never part of a preset: set those for your mosque below, then Save.

Factory default: Horsham, UK — timezone GMT0BST,M3.5.0/1,M10.5.0. Applying a preset needs the API token from Setup Authentication; without it the device answers 403 and the fields stay filled but unsaved.

Adhan Safety Margins (minutes)

Added to the astronomical calculation before display. Usually 0-5 min. This shifts the adhan; jamat is set separately below.

Adhan Audio

Off shows adhan times on the display but plays no audio. This does not affect the safety margins above.

0 mutes playback but still runs the pipeline; use Off to skip playback entirely and save power.

Prayer Timetable

You can upload your mosque's own timetable JSON to override the calculated times. Missing fields in an uploaded file are filled from your current configuration on read.

—

Note: Please save your configuration settings before uploading a file. Any settings saved after uploading will apply to the uploaded timetable. To preserve a custom timetable, finalize your settings first, then upload the file.

Factory Reset

Erases all saved settings (WiFi credentials, location, prayer configuration) and restarts the device in setup mode. This cannot be undone.

Firmware Update

Upload a .bin firmware image. The device flashes the inactive OTA slot, reboots into it, and validates itself on the next boot. If the new image fails to reach the handoff stage, the bootloader reverts to the current firmware automatically.
